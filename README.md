# myCTFtrack
История моих похождений на всяких ЦТФ, думаю что это когда нибудь да пригодиться, авось.

📖 О чем этот репозиторий?
Здесь я документирую свой путь в мире Capture The Flag (CTF). Я начал заниматься ИБ в 15 лет, самостоятельно изучая Kali Linux, сети и веб-уязвимости.

Мой подход — «Обглодать до костей». Мне недостаточно просто найти флаг; мне важно понять, почему уязвимость возникла и как работает архитектура системы (от логики JavaScript до внутреннего устройства нейросетей).
